# Agnes AI Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## Operator Steps

1. Open [https://agnes-ai.com/](https://agnes-ai.com/)
2. Sign up or sign in to Agnes AI
3. Open the dashboard, quick start, or developer area
4. Create an API key
5. Copy the key
6. Save it locally as `AGNES_AI_API_KEY`
7. Check the current free credits, free tokens, free models, and protocol notes
8. If the docs provide an OpenAI-compatible base URL, record that base URL and a starter model; if not, keep `check-console` in the template
9. Before importing into `CC Switch`, verify that the chosen model is still within the free scope

## Human Takeover Points

- Email verification or login challenge
- First-time console activation
- Review of current free quota and available models

## Final Checklist

- API key created successfully
- Free credits and free tokens visible in the dashboard
- Current free models recorded
- Base URL and protocol were copied from official developer pages, not third-party notes
