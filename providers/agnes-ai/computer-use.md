# Agnes AI Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## 操作脚本

1. 打开 [https://agnes-ai.com/](https://agnes-ai.com/)
2. 注册或登录 Agnes AI 账号
3. 进入 dashboard / quick start / developer 区域
4. 创建 API Key
5. 复制 key
6. 本地保存为环境变量：`AGNES_AI_API_KEY`
7. 查看当前免费 credits、免费 tokens、免费模型和适用协议说明
8. 若文档提供 OpenAI 兼容 base URL，再记录对应 base URL 与默认模型；若未公开写明，则在模板中保留 `check-console`
9. 导入 `CC Switch` 前，复核当前模型是否仍在免费范围内

## 人工接管点

- 邮箱验证或登录验证码
- 控制台首次开通确认
- 当前免费额度和可用模型复核

## 完成后核对

- API Key 是否创建成功
- 免费 credits / tokens 是否在控制台可见
- 当前免费模型是否已记录
- Base URL 和协议是否来自官方开发者页面，而不是第三方整理
