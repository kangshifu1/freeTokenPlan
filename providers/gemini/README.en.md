# Gemini

[中文](./README.md) | [English](./README.en.md)

- Website: [Gemini API Pricing](https://ai.google.dev/gemini-api/docs/pricing)
- Registration: sign in to Google AI Studio with a Google account, then create an API key; new keys are now created as `auth keys`
- Free tier: official long-term free tier, model-dependent; current public pricing examples are now led by Gemini 3.5 models, unrestricted `standard keys` are rejected from `2026-06-19`, inactive unrestricted `standard keys` may be blocked sooner, explicitly restricted `standard keys` can still work for now, and all `standard keys` are planned for shutdown in `2026-09`
- Compatibility: official [OpenAI compatibility](https://ai.google.dev/gemini-api/docs/openai) exists, but verify the downstream protocol requirement first
- Recommended for: beginner testing, lightweight coding, grounding demos
