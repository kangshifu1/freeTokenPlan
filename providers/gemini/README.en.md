# Gemini

[中文](./README.md) | [English](./README.en.md)

- Website: [Gemini API Pricing](https://ai.google.dev/gemini-api/docs/pricing)
- Registration: sign in to Google AI Studio with a Google account, then create an API key; new keys are now guided toward `auth keys`
- Free tier: official long-term free tier, model-dependent; unrestricted `standard keys` will be rejected from `2026-06-19`
- Compatibility: official [OpenAI compatibility](https://ai.google.dev/gemini-api/docs/openai) exists, but verify the downstream protocol requirement first
- Recommended for: beginner testing, lightweight coding, grounding demos
