# Gemini

[中文](./README.md) | [English](./README.en.md)

- 官网：[Gemini API Pricing](https://ai.google.dev/gemini-api/docs/pricing)
- 注册：Google 账号登录 AI Studio 后创建 API Key；新建 key 默认生成 `auth keys`
- 免费：官方长期提供 Free tier，具体按模型区分；当前公开定价示例已以 Gemini 3.5 系列为主，不受限制的 `standard keys` 已自 `2026-06-19` 起被拒绝，长期闲置的不受限制 `standard keys` 可能会更早被封锁，受显式限制的 `standard keys` 暂可继续使用，并计划在 `2026-09` 全部停用
- 兼容：官方提供 [OpenAI compatibility](https://ai.google.dev/gemini-api/docs/openai)，但建议先确认下游工具所需协议
- 推荐用途：免费试用、轻量 coding、搜索 grounding demo
