# Cerebras Computer Use Script

## 操作脚本

1. 打开 [https://inference.cerebras.ai/](https://inference.cerebras.ai/)
2. 注册或登录
3. 进入 API Keys 页面
4. 创建 key
5. 复制 key
6. 本地保存为环境变量：`CEREBRAS_API_KEY`
7. 查看 docs 中的 OpenAI SDK 页面
8. 在 CC Switch 中录入兼容信息

## 人工接管点

- 邮箱验证
- 风控校验

## 完成后核对

- 是否记录了当前控制台可用模型
- 是否记录了免费额度说明
