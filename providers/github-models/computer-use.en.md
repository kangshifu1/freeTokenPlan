## Operator Steps

1. Open [GitHub Models](https://docs.github.com/en/github-models)
2. Confirm the page says GitHub Models was retired on `2026-07-30`
3. Do not create a token, select a model, or record `https://models.github.ai/inference`
4. If any old config still references GitHub Models, remove it or mark it as historical so it is not imported into CC Switch

## Human Takeover Points

- No human takeover required; the service is retired

## Final Checklist

- GitHub Models retirement was confirmed and is no longer treated as a live access path
- Old endpoints / model IDs are no longer referenced as active configuration
