# Vercel AI Gateway

[中文](./README.md) | [English](./README.en.md)

- Website: [AI Gateway Pricing](https://vercel.com/docs/ai-gateway/pricing)
- Registration: sign in with a Vercel account and enable AI Gateway
- Free tier: the pricing page lists `$5/month` AI Gateway credits for each Vercel team account; credits start on the first AI Gateway request, and the monthly free credit no longer applies after purchasing credits
- Compatibility: designed for Vercel AI SDK and OpenAI-style routed calls; provider and model details follow current Vercel docs
- Recommended for: frontend / Vercel projects and multi-provider prototypes
