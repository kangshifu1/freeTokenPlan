# Vercel AI Gateway

[中文](./README.md) | [English](./README.en.md)

- Website: [AI Gateway Pricing](https://vercel.com/docs/ai-gateway/pricing)
- Registration: sign in with a Vercel account and enable AI Gateway
- Free tier: the pricing page lists `$5/month` AI Gateway credits for each Vercel team account; credits start on the first AI Gateway request, and the monthly free credit no longer applies after purchasing credits; free credits apply only to Vercel-marked eligible models
- Compatibility: designed for Vercel AI SDK and OpenAI-style routed calls; provider and model details follow current Vercel docs; BYOK provider keys are a paid feature, so they should not be treated as a default free-tier capability
- Recommended for: frontend / Vercel projects and multi-provider prototypes
