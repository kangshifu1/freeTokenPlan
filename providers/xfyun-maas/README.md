# 讯飞星辰 MaaS

[中文](./README.md) | [English](./README.en.md)

- 官网：[讯飞星辰 MaaS 模型广场](https://maas.xfyun.cn/modelSquare)
- 注册：讯飞账号 / 控制台登录后开通星辰 MaaS，并按页面要求完成必要认证
- 免费：模型广场可浏览模型与平台能力，但当前对编程工具接入更清晰、可公开复核的是企业版 `Astron Token Plan` 和 `Astron Coding Plan` 套餐文档；`Token Plan` 当前面向企业 / 团队场景并列出 `Kimi-K2`、`DeepSeek-V4`、`GLM-5.1`、`Qwen3.6`、`Claude-Sonnet-4.5` 等可切换模型示例；`Coding Plan` 当前说明 `首月版` 自 `2026-04-09 00:00` 起不再支持购买，并新增 `2026-06-15` 起生效的季度 `焕新版` 套餐说明，不应把它们写成长期全站免费 API
- 兼容：官方文档明确给出 `OpenAI` 和 `Anthropic` 两类兼容入口；`Token Plan` 与 `Coding Plan` 使用各自独立 base URL，不能和普通 `maas-api` 混用
- 推荐用途：中国大陆用户接入 `Claude Code`、`Cursor`、`OpenCode`、`OpenClaw` 等编程工具，按套餐选择统一模型路由
