# NVIDIA NIM

[中文](./README.md) | [English](./README.en.md)

- 官网：[NVIDIA NIM APIs](https://build.nvidia.com/)
- 注册：NVIDIA Developer / build.nvidia.com 账号登录后生成 API key
- 免费：官方 Build 页面继续提供面向开发和原型验证的免费 serverless NIM API，但可用性按模型页标注；当前页面会显示 `Free Endpoint` 为 `Available` 或 `Deprecated`，部分旧端点已退役，生产使用、速率限制和可用模型以 NVIDIA 当前账号与模型页为准
- 兼容：NVIDIA NIM API 示例使用 OpenAI 风格的 `chat/completions` 端点，常见 base URL 为 `https://integrate.api.nvidia.com/v1`
- 推荐用途：快速试用仍标记 `Free Endpoint: Available` 的 NVIDIA 托管模型、agent 原型、OpenAI 兼容客户端验证
