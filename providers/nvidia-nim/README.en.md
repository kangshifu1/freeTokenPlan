# NVIDIA NIM

[中文](./README.md) | [English](./README.en.md)

- Website: [NVIDIA NIM APIs](https://build.nvidia.com/)
- Registration: sign in with an NVIDIA Developer / build.nvidia.com account, then create an API key
- Free tier: NVIDIA Build still offers free serverless NIM APIs for development and prototyping, but availability is now model-page-specific; current pages mark `Free Endpoint` as `Available` or `Deprecated`, some older endpoints have retired, and production use, rate limits, and model availability depend on the current account and model page
- Compatibility: NIM API examples use an OpenAI-style `chat/completions` endpoint, commonly with `https://integrate.api.nvidia.com/v1`
- Recommended for: NVIDIA-hosted model trials where the model page still says `Free Endpoint: Available`, agent prototypes, and OpenAI-compatible client checks
