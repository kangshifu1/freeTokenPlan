# 腾讯混元

[中文](./README.md) | [English](./README.en.md)

- 官网：[混元大模型计费概述](https://cloud.tencent.com/document/product/1729/97731)
- 注册：腾讯云账号开通混元，按要求完成实名认证
- 免费：官方文档当前说明腾讯混元大模型相关功能将逐步迁移至 `TokenHub`；已购服务暂不受影响，开通新的模型服务或更多模型能力应前往 TokenHub
- 资源包：完成实名认证后首次点击“立即使用”会获得免费体验额度；当前混元生文免费额度为一次性免费资源包，列出的混元生文（不含 `Hunyuan-lite`）及混元多模态模型共享 `100万 tokens`，自开通日起 `1 年` 内有效；`Hunyuan-embedding` 单独列出 `100万 tokens / 1 年`
- 结算：系统按“免费资源包 > 付费资源包 > 按量后付费”顺序扣减；免费/付费资源包耗尽或到期后不会自动转入后付费，需在控制台主动开通后付费
- 兼容：腾讯混元提供 OpenAI 兼容接口文档，具体 base URL 和模型名以当前文档为准
- 推荐用途：中国大陆用户试用混元、轻量文本生成、OpenAI 兼容客户端接入
