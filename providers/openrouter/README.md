# OpenRouter

[中文](./README.md) | [English](./README.en.md)

- 官网：[OpenRouter Quickstart](https://openrouter.ai/docs/quickstart)
- 注册：邮箱或第三方账号注册后创建 API Key
- 免费：大量 `:free` 模型，免费账户可直接拿 key；官方限制页当前写明免费模型为 `20 requests/min`，累计购买额度低于 `$10` 时为 `50 requests/day`，达到 `$10` 后提升到 `1000 requests/day`
- 路由：可直接指定某个 `:free` 模型，也可用 `openrouter/free` 让 OpenRouter 从当前可用免费模型中自动选择
- 推荐用途：多模型试吃、快速接 OpenAI 兼容客户端
