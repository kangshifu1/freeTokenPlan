# Mistral Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## 操作脚本

1. 打开 [https://console.mistral.ai/](https://console.mistral.ai/)
2. 注册或登录
3. 打开 API Keys 页面
4. 新建 key
5. 复制 key
6. 本地保存为环境变量：`MISTRAL_API_KEY`
7. 查看 [Mistral Pricing](https://mistral.ai/pricing) 和 [Usage and limits](https://docs.mistral.ai/admin/billing-usage/usage-limits)：Free 定价卡宣传每月 `$10` credits，但使用限制文档说明这笔包含额度用于 Vibe 和 Studio，并不包含 API access
8. 查看 [API keys](https://docs.mistral.ai/admin/identity-access/api-keys)，如需 API 则激活账单和 pay-as-you-go，并记录 workspace 的订阅、账单状态和消费上限；不要把 Free 档宣传的 credits 当作免费 API 额度
9. 若导入 CC Switch，建议通过统一兼容网关接入

## 人工接管点

- 邮箱验证
- 可能的组织或 workspace 创建步骤

## 完成后核对

- 是否已创建 key
- 是否区分了 Vibe / Studio 包含额度与 API access，并记录 workspace 订阅、账单状态、pay-as-you-go 状态和消费上限
