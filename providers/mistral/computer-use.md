# Mistral Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## 操作脚本

1. 打开 [https://console.mistral.ai/](https://console.mistral.ai/)
2. 注册或登录
3. 打开 API Keys 页面
4. 新建 key
5. 复制 key
6. 本地保存为环境变量：`MISTRAL_API_KEY`
7. 查看 [Mistral Pricing](https://mistral.ai/pricing) 和 [API key quickstart](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key)，区分面向 Le Chat / Vibe 的 `Mistral Free` 与单独的 API access；当前定价页未列出 `$10/月` API credits
8. 查看 [API keys](https://docs.mistral.ai/admin/identity-access/api-keys)，确认 key 所属 workspace 具备 API access，并记录当前计划、账单状态和支付方式要求；创建 key 不代表获得免费 API 额度
9. 若导入 CC Switch，建议通过统一兼容网关接入

## 人工接管点

- 邮箱验证
- 可能的组织或 workspace 创建步骤

## 完成后核对

- 是否已创建 key
- 是否区分了 Le Chat / Vibe 免费计划与 API access，并记录 workspace 计划、账单状态和支付方式要求
