# Mistral Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## 操作脚本

1. 打开 [https://console.mistral.ai/](https://console.mistral.ai/)
2. 注册或登录
3. 打开 API Keys 页面
4. 新建 key
5. 复制 key
6. 本地保存为环境变量：`MISTRAL_API_KEY`
7. 查看 Studio / Console 与 [Mistral Pricing](https://mistral.ai/pricing) 页面，确认当前 API 免费模式和 `Mistral Free` / `Vibe for code` 计划说明
8. 若导入 CC Switch，建议通过统一兼容网关接入

## 人工接管点

- 邮箱验证
- 可能的组织或 workspace 创建步骤

## 完成后核对

- 是否已创建 key
- 是否记录当前免费模式条件
