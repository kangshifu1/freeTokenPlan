# Mistral

[中文](./README.md) | [English](./README.en.md)

- Website: [Mistral Pricing](https://mistral.ai/pricing)
- Registration: create a Mistral platform account
- Free tier: the current pricing card advertises `$10/month` in credits on Free, while the official usage-and-limits documentation says the Free-mode monthly budget is for trying Vibe and Studio and does not include API access
- Key / billing boundary: creating API keys and using the API require billing activation and pay-as-you-go. Check the current Console subscription, billing status, and spending limit; the advertised Free credits must not be treated as free API quota
- API access: configure API usage only when the current workspace is eligible; if an API call returns `402 Payment Required`, follow the current official error guidance to check account status
- Recommended for: trying Vibe / Studio within the included Free budget; API use only after the workspace explicitly activates billing and pay-as-you-go
