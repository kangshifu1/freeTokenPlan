# Mistral

[中文](./README.md) | [English](./README.en.md)

- 官网：[Mistral Pricing](https://mistral.ai/pricing)
- 注册：Mistral 平台注册
- 免费：当前定价卡在 Free 档宣传每月 `$10` credits；但官方 Usage and limits 文档说明 Free mode 的月度预算用于试用 Vibe 和 Studio，并不包含 API access
- Key / 计费边界：创建 API key 和调用 API 需要激活账单并启用 pay-as-you-go。需在 Console 核对当前订阅、账单状态和消费上限；不能把 Free 档宣传的 credits 当作免费 API 调用额度
- API 接入：按当前 workspace 的 API access 资格配置；如 API 请求返回 `402 Payment Required`，按当前官方错误说明检查账户状态
- 推荐用途：在 Free 档包含的预算内试用 Vibe / Studio；API 仅在 workspace 明确激活账单和 pay-as-you-go 后使用
