# Mistral

[中文](./README.md) | [English](./README.en.md)

- 官网：[Mistral Pricing](https://mistral.ai/pricing)
- 注册：Mistral 平台注册
- 免费：当前定价页的 `Mistral Free` 是面向 Le Chat 的免费计划，包含有限的 `Vibe` 编程能力；页面未列出 `$10/月` API credits。API 使用与消费者端 Free 计划分开
- Key / 计费边界：官方 API key quickstart 要求 workspace 具备 API access。需在 Console 核对当前计划、账单状态和支付方式要求；创建 key 不代表获得免费 API 调用额度
- API 接入：按当前 workspace 的 API access 资格配置；如 API 请求返回 `402 Payment Required`，按当前官方错误说明检查账户状态
- 推荐用途：Le Chat / Vibe 免费体验；API 仅在 workspace 明确具备 API access 时使用
