# Mistral

[中文](./README.md) | [English](./README.en.md)

- 官网：[Mistral Pricing](https://mistral.ai/pricing)
- 注册：Mistral 平台注册
- 免费：官方定价页继续列出 `Mistral Free` 计划，并说明包含有限的 `Vibe for code` 能力和 `$10/月` API credits；Studio quickstart 说明 API `Free mode` 默认启用，免费试用无需先绑定信用卡，带有限 rate limit，面向评估与原型验证
- Key / 计费边界：API key 不绑定特定计费模式；同一个 key 会按组织当前计划和账单状态从 `Free mode` 切到 `Pay as you go` 或更高 tier；官方 developer quickstart 也把 `402 Payment Required` 解释为账号缺少支付方式，所以首次 API 请求前仍要核对当前 workspace 的支付方式与账单状态
- 升级：需要更高限额时升级到 `Scale` 计划，随后按累计账单进入更高 usage tier
- 推荐用途：模型风格试用、轻量开发测试
