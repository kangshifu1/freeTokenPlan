# Mistral Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## Operator Steps

1. Open [https://console.mistral.ai/](https://console.mistral.ai/)
2. Register or sign in
3. Open the API keys page
4. Create a key
5. Copy the key
6. Save it locally as `MISTRAL_API_KEY`
7. Check Studio / Console, [Mistral Pricing](https://mistral.ai/pricing), [Activate Studio and generate an API key](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key), and [Send your first API request](https://docs.mistral.ai/getting-started/quickstarts/developer/first-api-request) for current API `Free mode`, no-credit-card free-trial, rate-limit, Mistral Free / Vibe for code wording, whether the Free plan still lists `$10/mo` API credits, and whether the current docs still map `402 Payment Required` to an account with no payment method
8. Check [API keys](https://docs.mistral.ai/admin/identity-access/api-keys), then record the current plan for the key's workspace; do not label the key as a "free key" or "PAYG key" because the official docs say keys follow the workspace plan / billing state
9. For `CC Switch`, prefer a compatible gateway before import

## Human Takeover Points

- Email verification
- Organization or workspace setup if required

## Final Checklist

- Key created
- Current free-mode conditions, Free-plan API credits, workspace plan, payment-method requirement, and key / billing boundary recorded
