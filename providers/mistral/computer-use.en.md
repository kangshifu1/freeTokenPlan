# Mistral Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## Operator Steps

1. Open [https://console.mistral.ai/](https://console.mistral.ai/)
2. Register or sign in
3. Open the API keys page
4. Create a key
5. Copy the key
6. Save it locally as `MISTRAL_API_KEY`
7. Check the pricing or models page for the current free-mode wording
8. For `CC Switch`, prefer a compatible gateway before import

## Human Takeover Points

- Email verification
- Organization or workspace setup if required

## Final Checklist

- Key created
- Current free-mode conditions recorded
