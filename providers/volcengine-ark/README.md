# 火山方舟

[中文](./README.md) | [English](./README.en.md)

- 官网：[火山方舟文档](https://www.volcengine.com/docs/82379)
- 注册：火山引擎账号开通方舟，按要求完成实名认证
- 免费：官方文档和控制台会展示免费推理额度、安心体验模式和活动额度；豆包搜索 / `web_search` 普通免费包与 Agent Plan 套餐搜索额度分开计算，模型价格页当前示例为每个账号一次性 `500` 次 `web_search` 调用；普通推理额度、搜索工具额度、套餐额度、模型和有效期仍以当前控制台 / 活动页 / 套餐页为准
- 计划说明：当前方舟文档已把 `Agent Plan` / `Coding Plan` 作为单独导航和计费/活动入口；豆包搜索 / `web_search` 免费包和套餐搜索额度都属于搜索工具服务额度，`Agent Plan` / `Coding Plan` 走独立套餐和活动规则，不应默认等同于长期全站免费 API 额度
- 兼容：方舟文档包含 OpenAI 兼容和多种 AI 工具接入说明，`Agent Plan` / `Coding Plan` 工具页应作为编程工具接入的优先确认入口；导入前要分开核对普通推理 endpoint、套餐 endpoint、模型名和环境变量
- 推荐用途：中国大陆用户试用豆包 / DeepSeek 等模型、Coding Plan / Agent Plan 工具接入、轻量 agent 测试
