# SiliconFlow Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## Operator Steps

1. Open [https://cloud.siliconflow.cn/](https://cloud.siliconflow.cn/)
2. Register or sign in
3. Complete required verification or real-name authentication
4. Open the API keys page
5. Create a key
6. Copy the key
7. Save it locally as `SILICONFLOW_API_KEY`
8. Open the models page and filter models currently labeled `free`
9. Record 1 to 3 currently free models
10. If using `CC Switch`, follow the official CC Switch guide for the compatible endpoint and default model

## Human Takeover Points

- Login verification
- Phone or email verification
- Real-name authentication

## Final Checklist

- Required account verification is complete
- Current free model list recorded
- Claude Code compatibility notes saved if needed
- CC Switch route recorded from the official guide if needed
