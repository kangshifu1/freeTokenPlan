# SiliconFlow Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## Operator Steps

1. Open [https://cloud.siliconflow.cn/](https://cloud.siliconflow.cn/)
2. Register or sign in
3. Open the API keys page
4. Create a key
5. Copy the key
6. Save it locally as `SILICONFLOW_API_KEY`
7. Open the models page and filter models currently labeled `free`
8. Record 1 to 3 currently free models
9. Add the provider and default model to `CC Switch`

## Human Takeover Points

- Login verification
- Phone or email verification

## Final Checklist

- Current free model list recorded
- Claude Code compatibility notes saved if needed
