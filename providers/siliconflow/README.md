# SiliconFlow

[中文](./README.md) | [English](./README.en.md)

- 官网：[SiliconFlow Docs](https://docs.siliconflow.cn/)
- 注册：注册账号，按平台要求创建 API Key；官方 `CC Switch` 教程的推广注册路径要求完成实名认证
- 免费：官方 Quickstart 引导用户到模型广场查看当前模型可用性、价格和用户最高限速，部分模型可能在控制台标注为免费；官方 `CC Switch` 教程当前提示通过其注册链接注册并完成实名认证后可获 `16元` 赠送余额
- 兼容：官方提供 [Claude Code](https://docs.siliconflow.cn/cn/usercases/use-siliconcloud-in-ClaudeCode) 和 [CC Switch](https://docs.siliconflow.cn/cn/usercases/use-siliconcloud-in-ccswitch) 接入说明
- 推荐用途：中国区多模型试用、接 `Claude Code`
