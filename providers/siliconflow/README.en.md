# SiliconFlow

[中文](./README.md) | [English](./README.en.md)

- Website: [SiliconFlow Docs](https://docs.siliconflow.cn/)
- Registration: create an account, complete real-name verification, then generate an API key; an official update says unverified users cannot use platform functions from `2026-05-15`
- Free tier: official docs say free models are available after real-name verification, and some models are explicitly labeled as free. The official `CC Switch` guide currently notes a `CNY 16` reward balance after registering through that path and completing real-name verification
- Compatibility: official guides exist for [Claude Code](https://docs.siliconflow.cn/quickstart/use_with_claude_code) and [CC Switch](https://docs.siliconflow.cn/cn/userguide/introduction/use-with-cc-switch)
- Recommended for: China-based multi-model testing and `Claude Code` connectivity
