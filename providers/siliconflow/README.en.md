# SiliconFlow

[中文](./README.md) | [English](./README.en.md)

- Website: [SiliconFlow Docs](https://docs.siliconflow.cn/)
- Registration: create an account and generate an API key; the current official real-name FAQ says missing verification affects recharge and invoicing, while the promoted `CC Switch` registration path requires real-name verification before claiming the reward balance
- Free tier: official quickstart points users to the model square for current model availability, pricing, and per-user rate limits; some models may be labeled free in the console. The official `CC Switch` guide currently notes a `CNY 16` reward balance after registering through that path and completing real-name verification
- Compatibility: official guides exist for [Claude Code](https://docs.siliconflow.cn/cn/usercases/use-siliconcloud-in-ClaudeCode) and [CC Switch](https://docs.siliconflow.cn/cn/usercases/use-siliconcloud-in-ccswitch)
- Recommended for: China-based multi-model testing and `Claude Code` connectivity
