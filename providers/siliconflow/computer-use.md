# SiliconFlow Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## 操作脚本

1. 打开 [https://cloud.siliconflow.cn/](https://cloud.siliconflow.cn/)
2. 注册或登录
3. 打开 API Keys 页面
4. 创建 key
5. 复制 key
6. 本地保存为环境变量：`SILICONFLOW_API_KEY`
7. 打开模型页，筛选当前标注 `免费` 的模型
8. 记录 1 到 3 个当前免费模型
9. 在 CC Switch 中新增供应商并录入兼容地址和默认模型

## 人工接管点

- 登录验证
- 手机或邮箱验证码

## 完成后核对

- 免费模型列表是否已记录
- 是否已保存 Claude Code 兼容接入备注
