# Cohere Computer Use Script

[中文](./computer-use.md) | [English](./computer-use.en.md)

## 操作脚本

1. 打开 [https://dashboard.cohere.com/](https://dashboard.cohere.com/)
2. 点击注册或登录
3. 完成邮箱验证
4. 进入 API Keys 页面
5. 创建一个 trial key
6. 复制 key
7. 本地保存为环境变量：`COHERE_API_KEY`
8. 打开模型文档，优先记录当前试用模型集，例如 `Command A+`、`Command A`、`Command A Reasoning`、`Command A Translate`、`Command A Vision`、`Command R7B`、`Command R+`、`Command R`、`North Mini Code`
9. 如果要放入 CC Switch，优先经由兼容代理或统一网关接入

## 人工接管点

- 邮箱验证
- 安全校验

## 完成后核对

- 是否确认为 trial key
- 是否记录当前试用速率限制
- 是否把模型是否支持免费试用、是否标注 `fast` 与当前文档日期一起记录
