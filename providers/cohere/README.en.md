# Cohere

[中文](./README.md) | [English](./README.en.md)

- Website: [Cohere Rate Limits](https://docs.cohere.com/docs/rate-limits)
- Registration: create a Cohere account and generate a trial key
- Free tier: free trial keys with documented limits; Cohere says trial keys and production keys for some newer Chat variants are capped at `1,000 API calls/month`
- Limits: current trial Chat API limits are generally `20 req/min`; `Embed` is `2,000 inputs/min`, and `Rerank` is `10 req/min`; current model docs now surface `Command A+`, `Command A`, `Command A Reasoning`, `Command A Translate`, `Command A Vision`, `Command R7B`, `Command R+`, `Command R`, and `North Mini Code` as the current trial model set
- Usage boundary: Cohere pricing says trial keys are not permitted for production or commercial use
- Recommended for: evaluation, prompt validation, lightweight testing
- Reference: [Model docs](https://docs.cohere.com/docs/models)
